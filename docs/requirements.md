## User Stories

### Requirements - Data Sources

As a *PHD student*, I want to view the source data comes from, so that I am able to see where collected data originates from.
As a *PHD student*, I want to view the types of data a source provides so that I can determine whether it is suitable for my research needs.
As a *PHD student*, I want to get a description of the data so that I am able to understand whether the data is suitable for my research needs and compare across methods.
As a *group lead*, I want to limit the available data sources to *GitHub, Stack Overflow, Jira, app stores, Travis CI, Jenkins, mailing lists, and the npm registry* so that students can access a clearly defined set of reliable sources.

### Requirements - Collection Methods

As a *PHD student*, I want to view the name of the method used to collect data, so that I am able to gather further data using said method.
As a *PHD student*, I want to view what the data source collected is used for, so that I am able to assess whether it fits my research needs and compare.
As a *PHD student*, I want to view the advantages and limitations of each collected data source so that I can assess its suitability for my research needs and compare across methods.
As a *group lead*, I want to limit the data collection methods to *REST APIs (GitHub, Overflow), GraphQL, Web Scraping (Selenium and Beautiful Soup), Database Dumps, and Manual Downloads (CSV Exports)* so that students can access a research acceptable data collection method.

### Requirements - Analysis Methods
 
As a *PHD student*, I want to view the names of supported analysis methods so that I can identify the options available for my research.
As a *PHD student*, I want to view the forms of analysis each supported method enables so that I can understand how it can be applied to my data.
As a *PHD student*, I want to view common use cases for each supported analysis method so that I can assess its suitability for my research needs and compare across methods.
As a *group lead*, I want to limit the supported analysis methods to *Statistical Analysis, Regression Analysis, Thematic Analysis, Grounded Theory, Machine Learning, Time Series Analysis, Network Analysis, and Visualization* so that students work within a clearly defined scope.

### Requirements - Publication Venues

As a *PHD student*, I want to view the names and associated abbreviation of a venue so that I can see the possible available venues to publish research.
As a *PHD student*, I want to view the type of venue (Journal or Conference) of a venue so that I can assess whether the venue is suitable for my publication needs
As a *PHD student*, I want to view the focus area of the venue so that I can assess whether that venue matches my research area
As a *PhD student*, I want to view a metric indicating a publication venue’s relevance to *Mining Software Repositories (MSR)* so that I can assess its suitability for my research topic.
As a *group lead*, I want to limit conferences to the following *ICSE, FSE, ASE, MSR, EASE, SANER* so that students are able to assess research venues from pre-defined creditable and relevant conferences.
As a *group lead*, I want to limit journals to the following *EMSE, TSE, TOSEM* so that students are able to assess research venues from pre-defined creditable and relevant journals.

### Requirements - Webpage 

As a *PHD student*, I want a simple and content based view of webpage so that I can quickly assess the relevant content for me.
As a *group lead*, I want to switch between sections, such as Data Sources and Collection Methods, using clearly labelled tabs or buttons at the top of the page, with each section’s content displayed in a simple table or list, so that I can easily find and browse the information I need.
