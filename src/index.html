Data Sources

Source Name Data it Provides Description
GitHub Repositories, Commits, Pull Requests, Issues, Stars GitHub provides software repository data, including source code, commit histories, branches, pull requests, issues, releases, and contributor activity. This data can be used to study how software evolves, how developers collaborate, and how projects manage bugs and contributions
Stack Overflow Questions, Answers, Tags, User Reputation Stack Overflow provides programming questions and answers, along with tags, comments, votes, accepted answers, and timestamps. This data can be used to study common programming challenges, developer knowledge sharing, and trends in technologies and tools.
JIRA Issue Tracking, Sprint Data, Bug Reports Jira provides issue and project management data, including bug reports, tasks, feature requests, priorities, statuses, assignees, comments, and timestamps. This data can be used to study how teams track defects, manage workloads, and monitor software development progress.
App Stores Google Play, Apple app store reviews, ratings, downloads App stores such as Google Play and the Apple App Store provide app descriptions, user reviews, ratings, version histories, and release dates. Download and installation metrics may also be available, depending on the platform and access permissions. This data can be used to study user satisfaction, reported bugs, feature requests, and app adoption trends.
Travis CI / Jenkins Build logs, test results, and deployment data Travis CI provides continuous integration data, including build histories, build statuses, execution times, job configurations, and logs from compilation and testing. This data can be used to study build failures, test reliability, and the impact of code changes on software integration.
Mailing Lists Developer Discussions and Archives Mailing lists provide archived developer discussions, including messages, conversation threads, sender information, and timestamps. This data can be used to study technical decisions, proposed features, reported bugs, and collaboration within software development communities.
NPM Registry Package dependencies, downloads, and versions The npm registry provides software package data, including package names, descriptions, versions, dependencies, maintainers, publication dates, and download counts. This data can be used to study package popularity, dependency relationships, release patterns, and the evolution of the JavaScript ecosystem.
